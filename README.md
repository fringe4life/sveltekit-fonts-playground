# sveltekit-fonts-playground

Public **deploy target** for the SvelteKit experimental fonts playground (GitHub Pages and host CLIs).

The implementation lives in the Kit monorepo:

https://github.com/fringe4life/kit/tree/experimental-fonts/playgrounds/fonts

This repository is **not** a second copy of the app. Source of truth remains `fringe4life/kit` (`playgrounds/fonts`). One site, many adapters — not six apps.

Later syncs may sparse-copy that playground here. Until then, this repo is a placeholder so Pages and host Git integrations can point at a public repo instead of the Kit monorepo.
